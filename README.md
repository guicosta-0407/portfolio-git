# Portfólio Git

Repositório criado para a **Atividade 2** do curso *Fundamentos de Git e GitHub* (CEFET-MG/UFCI-MG). Ele reúne os arquivos de um portfólio pessoal simples e serve como ambiente de prática dos comandos básicos do Git.

## Sobre o projeto

O objetivo deste repositório é treinar o fluxo fundamental do controle de versão: criar um repositório, acompanhar mudanças, registrar commits e consultar o histórico. O conteúdo do portfólio (apresentação, projetos e contato) serve de material para esse treino.

### Comandos praticados

| Comando | Para que serve |
|---|---|
| `git init` | Cria um repositório Git na pasta |
| `git status` | Mostra o estado atual dos arquivos |
| `git add` | Seleciona mudanças para o próximo commit |
| `git commit` | Registra as mudanças no histórico |
| `git diff` | Mostra o que foi alterado em cada arquivo |
| `git log` | Lista o histórico de commits |

## Estrutura do repositório

```
portfolio-git/
├── README.md      # Apresentação do projeto
├── sobre.md       # Informações sobre mim
├── contato.md     # Canais de contato
├── LICENCA.md     # Licença do projeto
└── .gitignore     # Arquivos e pastas ignorados pelo Git
```

O `.gitignore` ignora arquivos `*.log` e a pasta `.vscode/`, que são locais e não precisam ir para o repositório.
