# Portfólio Git

Repositório criado para a Atividade 2.

## Sobre o projeto

Este projeto reúne arquivos simples de um portfólio pessoal e serve para treinar os principais comandos do Git: `git init`, `git status`, `git add`, `git commit`, `git diff` e `git log`.

## Estrutura

- `README.md`: apresentação do projeto
- `sobre.md`: informações sobre mim
- `.gitignore`: arquivos e pastas ignorados pelo Git (`*.log` e `.vscode/`)
