### Commits e histórico

Commit é o ato de registrar uma edição ou criação no projeto, que pode ser enviada ao GitHub ou mantida no repositório local. O histórico serve para ver o que foi alterado em cada commit e também como backup, caso algum commit dê problema.

### Branches

Uma branch é como uma ramificação da "linha do tempo" do projeto, em que as alterações feitas nela não afetam diretamente o projeto principal. Ela é necessária para fazer atualizações com mais etapas de conferência antes de integrá-las ao projeto principal.

### Pull Requests

É o processo de comparar a branch ramificada com a `main` e depois uni-las, caso não haja nenhum erro. É útil para que mais de uma pessoa analise a atualização antes de ela entrar no projeto principal.

### Issues

São "tarefas" a serem feitas no projeto. São úteis para organizar o projeto e o seu desenvolvimento, sem deixar passos importantes para trás.
